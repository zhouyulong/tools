# traceTime M1（可用核心）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可用的计时核心：创建/开始/暂停（带原因）/继续/完成/放弃 + SQLite 持久化 + 常驻悬浮小组件基础 UI。

**Architecture:** Rust 层（rusqlite + 状态机）是唯一事实来源，Svelte 前端仅展示与发起动作，通过 Tauri IPC 调用。计时基于真实时间戳（工作段起止），不做内存累加。

**Tech Stack:** Tauri 2、Svelte 5 (Vite)、rusqlite (bundled SQLite)、serde、uuid、chrono。

**Spec:** `docs/2026-11-26-tracetime-design.md`

## Global Constraints

- 计时基于真实时间戳（墙钟 UTC ISO8601），禁止用 tick 累加时长
- 工作段（segments）与事件（events）只增不改；所有分析在查询层推导
- 暂停原因枚举：`rest | disturbance | switch | other`；默认 `other`
- 任务标签：可选，预设 `科研 / 行政 / 杂务`，默认沿用上次使用的标签
- 数据库文件位于各平台标准应用数据目录（`tauri-plugin-fs` 的 appDataDir 或 `directories` crate 的 `ProjectDirs::from("", "", "traceTime")`）
- 单任务模型：同一时刻至多一个非终态任务（pending/running/paused）
- 事件 kind 枚举：`created | started | paused | resumed | finished | abandoned`（M1 只用这些）
- Windows/Linux 文件路径统一正斜杠风格使用相对路径，仓库根为 `traceTime/`（本目录）
- 每个 Task 完成后必须 `cargo test`（Rust 部分）全绿并提交一次

    CREATE TABLE tasks (
      id             TEXT PRIMARY KEY,
      name           TEXT NOT NULL,

      status         TEXT NOT NULL,

      finished_at    TEXT,

      key   TEXT PRIMARY KEY,
      value TEXT NOT NULL

    CREATE INDEX idx_events_task_time ON events(task_id, at);
    CREATE INDEX idx_segments_task ON segments(task_id, started_at);

pub fn open(path: &Path) -> rusqlite::Result<Connection> {
    let conn = Connection::open(path)?;
    migrate(&conn)?;
    Ok(conn)
}

pub fn open_in_memory() -> rusqlite::Result<Connection> {
    let conn = Connection::open_in_memory()?;
    migrate(&conn)?;
    Ok(conn)
}

fn migrate(conn: &Connection) -> rusqlite::Result<()> {
    conn.execute_batch(
        "CREATE TABLE IF NOT EXISTS schema_migrations (version INTEGER PRIMARY KEY);",
    )?;
    let current: i64 = conn.query_row(
        "SELECT COALESCE(MAX(version), 0) FROM schema_migrations",
        [],
        |r| r.get(0),
    )?;
    for (i, sql) in MIGRATIONS.iter().enumerate() {
        let version = (i + 1) as i64;
        if version > current {
            conn.execute_batch(sql)?;
            conn.execute(
                "INSERT INTO schema_migrations (version) VALUES (?1)",
                [version],
            )?;
        }
    }
    Ok(())
}

  - `pub fn resume(&self) -> Result<TaskDto, String>`

- [ ] **Step 2: 实现 Tracker**

```rust
use crate::store;
use rusqlite::Connection;
use serde::Serialize;
use std::sync::Mutex;

const PAUSE_REASONS: [&str; 4] = ["rest", "disturbance", "switch", "other"];

#[derive(Debug, Serialize, Clone)]
pub struct TaskDto {
    pub id: String,
    pub name: String,
    pub est_seconds: i64,
    pub status: String,
    pub tag: Option<String>,
    pub net_seconds: i64,
    pub created_at: String,
    pub finished_at: Option<String>,
}

pub struct Tracker {
    pub(crate) conn: Mutex<Connection>,
}

fn now() -> String {
    chrono::Utc::now().to_rfc3339()
}

fn row_to_task(r: &rusqlite::Row) -> rusqlite::Result<TaskDto> {
    Ok(TaskDto {
        id: r.get("id")?,
        name: r.get("name")?,
        est_seconds: r.get("est_seconds")?,
        status: r.get("status")?,
        tag: r.get("tag")?,
        net_seconds: r.get("net_seconds")?,
        created_at: r.get("created_at")?,
        finished_at: r.get("finished_at")?,
    })
}

impl Tracker {
    pub fn new(conn: Connection) -> Tracker {
        Tracker { conn: Mutex::new(conn) }
    }

    fn add_event(conn: &Connection, task_id: &str, kind: &str, detail: Option<&str>) {
        conn.execute(
            "INSERT INTO events (task_id, at, kind, detail) VALUES (?1, ?2, ?3, ?4)",
            rusqlite::params![task_id, now(), kind, detail],
        )
        .expect("insert event");
    }

    fn net_seconds(conn: &Connection, task_id: &str) -> i64 {
        conn.query_row(
            "SELECT COALESCE(SUM(
                CAST(strftime('%s', ended_at) AS INTEGER)
              - CAST(strftime('%s', started_at) AS INTEGER)
             ), 0)
             FROM segments WHERE task_id = ?1 AND kind = 'work'",
            [task_id],
            |r| r.get(0),
        )
        .unwrap_or(0)
    }

    fn gross_seconds(conn: &Connection, task_id: &str) -> i64 {
        conn.query_row(
            "SELECT COALESCE(CAST(strftime('%s', ?2) AS INTEGER), CAST(strftime('%s','now') AS INTEGER))
                   - CAST(strftime('%s', created_at) AS INTEGER)
             FROM tasks WHERE id = ?1",
            rusqlite::params![task_id, now()],
            |r| r.get(0),
        )
        .unwrap_or(0)
    }

    fn get_task(conn: &Connection, task_id: &str) -> Option<TaskDto> {
        conn.query_row("SELECT * FROM tasks WHERE id = ?1", [task_id], row_to_task).ok()
    }

    fn active_task(conn: &Connection) -> Option<TaskDto> {
        let id: String = conn
            .query_row(
                "SELECT id FROM tasks WHERE status IN ('pending','running','paused') LIMIT 1",
                [],
                |r| r.get(0),
            )
            .ok()?;
        Self::get_task(conn, &id)
    }

    fn close_open_segment(conn: &Connection, task_id: &str) {
        let n = conn
            .execute(
                "UPDATE segments SET ended_at = ?2
                 WHERE task_id = ?1 AND ended_at IS NULL",
                rusqlite::params![task_id, now()],
            )
            .expect("close segment");
        assert!(n <= 1, "at most one open segment");
    }

    /// 补齐 net_seconds / gross_seconds 的实时计算，返回给前端
    fn with_live_net(conn: &Connection, mut task: TaskDto) -> TaskDto {
        task.net_seconds = Self::net_seconds(conn, &task.id);
        task
    }

    fn require_active(&self) -> Result<(Connection, TaskDto), String> {
        let conn = self.conn.lock().map_err(|_| "lock poisoned")?;
        match Self::active_task(&conn) {
            Some(t) => Ok((conn, t)),
            None => Err("no active task".into()),
        }
    }

    pub fn create_task(&self, name: &str, est_seconds: i64, tag: Option<&str>) -> Result<TaskDto, String> {
        if name.trim().is_empty() {
            return Err("task name is required".into());
        }
        if est_seconds <= 0 {
            return Err("est_seconds must be positive".into());
        }
        let mut conn = self.conn.lock().map_err(|_| "lock poisoned")?;
        if Self::active_task(&conn).is_some() {
            return Err("another task is active".into());
        }
        let id = uuid::Uuid::new_v4().to_string();
        let ts = now();
        conn.execute(
            "INSERT INTO tasks (id, name, est_seconds, status, created_at, tag)
             VALUES (?1, ?2, ?3, 'running', ?4, ?5)",
            rusqlite::params![id, name.trim(), est_seconds, ts, tag],
        )
        .map_err(|e| e.to_string())?;
        conn.execute(
            "INSERT INTO segments (task_id, started_at, ended_at, kind)
             VALUES (?1, ?2, NULL, 'work')",
            rusqlite::params![id, ts],
        )
        .map_err(|e| e.to_string())?;
        Self::add_event(&conn, &id, "created", None);
        Self::add_event(&conn, &id, "started", None);
        Ok(Self::with_live_net(&conn, Self::get_task(&conn, &id).unwrap()))
    }

    pub fn pause(&self, reason: &str) -> Result<TaskDto, String> {
        if !PAUSE_REASONS.contains(&reason) {
            return Err(format!("invalid pause reason: {reason}"));
        }
        let (conn, task) = self.require_active()?;
        if task.status != "running" {
            return Err(format!("cannot pause task in status {}", task.status));
        }
        Self::close_open_segment(&conn, &task.id);
        let detail = serde_json::json!({ "reason": reason }).to_string();
        Self::add_event(&conn, &task.id, "paused", Some(&detail));
        let updated = conn.execute(
            "UPDATE tasks SET status='paused' WHERE id=?1",
            [&task.id],
        ).map_err(|e| e.to_string())?;
        assert_eq!(updated, 1);
        Ok(Self::with_live_net(&conn, task))
    }

    pub fn resume(&self) -> Result<TaskDto, String> {
        let (conn, task) = self.require_active()?;
        if task.status != "paused" {
            return Err(format!("cannot resume task in status {}", task.status));
        }
        conn.execute(
            "INSERT INTO segments (task_id, started_at, ended_at, kind)
             VALUES (?1, ?2, NULL, 'work')",
            rusqlite::params![task.id, now()],
        ).map_err(|e| e.to_string())?;
        Self::add_event(&conn, &task.id, "resumed", None);
        conn.execute("UPDATE tasks SET status='running' WHERE id=?1", [&task.id])
            .map_err(|e| e.to_string())?;
        Ok(Self::with_live_net(&conn, Self::get_task(&conn, &task.id).unwrap()))
    }

    fn terminate(&self, status: &str, kind: &str) -> Result<TaskDto, String> {
        let (conn, task) = self.require_active()?;
        if task.status == "running" {
            Self::close_open_segment(&conn, &task.id);
        }
        let net = Self::net_seconds(&conn, &task.id);
        let gross = Self::gross_seconds(&conn, &task.id);
        let finished_at = now();
        conn.execute(
            "UPDATE tasks SET status=?2, finished_at=?3, net_seconds=?4, gross_seconds=?5 WHERE id=?1",
            rusqlite::params![task.id, status, finished_at, net, gross],
        ).map_err(|e| e.to_string())?;
        Self::add_event(&conn, &task.id, kind, None);
        let mut t = Self::get_task(&conn, &task.id).unwrap();
        t.net_seconds = net;
        Ok(t)
    }

    pub fn finish(&self) -> Result<TaskDto, String> {
        self.terminate("done", "finished")
    }

    pub fn abandon(&self) -> Result<TaskDto, String> {
        self.terminate("abandoned", "abandoned")
    }

    pub fn current(&self) -> Result<Option<TaskDto>, String> {
        let conn = self.conn.lock().map_err(|_| "lock poisoned")?;
        Ok(Self::active_task(&conn).map(|t| Self::with_live_net(&conn, t)))
    }

    pub fn list_finished(&self) -> Result<Vec<TaskDto>, String> {
        let conn = self.conn.lock().map_err(|_| "lock poisoned")?;
        let mut stmt = conn
            .prepare("SELECT * FROM tasks WHERE status IN ('done','abandoned') ORDER BY finished_at DESC")
            .map_err(|e| e.to_string())?;
        let rows = stmt
            .query_map([], row_to_task)
            .map_err(|e| e.to_string())?;
        Ok(rows.filter_map(|r| r.ok()).collect())
    }
}
```

// src/lib/format.ts
export function fmtHMS(totalSeconds: number): string {
  const s = Math.max(0, Math.floor(totalSeconds))
  const h = Math.floor(s / 3600)
  const m = Math.floor((s % 3600) / 60)
  const sec = s % 60
  const pad = (n: number) => String(n).padStart(2, '0')
  return `${pad(h)}:${pad(m)}:${pad(sec)}`
}
