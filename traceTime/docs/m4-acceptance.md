# M4 桌面体验手动验收清单

> 状态：待人工验收。自动化验证不能替代窗口透明、拖拽、位置记忆、崩溃恢复与跨平台视觉检查。

## 1. 连续异常退出恢复

- [ ] 在测试数据库创建一个任务，先计时一段并正常暂停，记下已封存工作段的净时长。继续同一任务，待运行中计时增加后强制结束应用进程。
- [ ] 首次重开：同一任务显示为**暂停**，净时长等于上一步记下的已封存净时长；崩溃前尚未封存的运行段不计入净时长。用测试库只读查询或轨迹记录确认该回合恰好新增一个 `anomaly` 段、一个 `paused` 事件（`reason: anomaly`）和一个 `anomaly_recovered` 事件，原工作段不变。
- [ ] 不继续任务，立即退出并再次重开：仍为暂停、净时长不变，且不新增异常段或上述两个事件。随后明确继续任务，运行时再次强制退出并重开；确认同一任务仍暂停，净时长仍只计已封存工作，且仅新增第二回合的一个异常段和各一个恢复事件。
- [ ] 对已超时任务继续计时：从恢复后的净时长起满一个配置的重复周期前，不得触发新一轮超时提醒。再执行暂停、继续、完成，确认轨迹正常。
- [ ] 另起一个正在计时的任务；通过第二个进程启动相同应用（而非仅切回已有窗口）。确认原主窗口可用、条件允许时被显示并聚焦，任务仍运行，未新增任何恢复记录。

## 2. 窗口位置记忆

- [ ] 将主小组件拖到非默认位置，正常退出并重开；确认窗口回到上次位置。
- [ ] 快速连续拖动后立即正常退出并重开；确认保存的是最后排队的位置，而不是中途位置。
- [ ] 把窗口拖到另一显示器后重开，确认仍可见。拔掉该显示器，或在隔离测试库中留下缺失一项、非数字、越界或屏幕外的旧坐标后重开，确认能启动并留在默认位置。

## 3. 背景三态

- [ ] 在设置中依次选择 `glass`、`translucent`、`opaque` 并保存；确认主小组件立即采用实际生效模式，重开后仍保持该设置。
- [ ] `glass`：支持的平台显示原生模糊/材质效果，文字与控件边界清晰。
- [ ] `translucent`：显示深色半透明背景，不被 WebView 的不透明底色遮挡。
- [ ] `opaque`：显示完整不透明深色背景，无透底或局部透明残留。

## 4. 平台降级

- [ ] 在不支持原生玻璃效果的平台或会话中选择 `glass`；确认应用不中断，并自动降级为 `translucent`。
- [ ] 保存后设置页仍选中“毛玻璃（默认）”，并显示“当前实际：半透明纯色”。重启应用再打开设置，确认选项与实际模式提示仍一致；改为不透明并保存后，降级提示消失。
- [ ] 至少在目标发布平台各检查一次；记录操作系统、桌面会话及实际生效模式。

## 5. 闲置淡化与悬停恢复

- [ ] 只打开主小组件且不操作 10 秒；确认整个主壳体在约 300ms 内淡化到约 20% 不透明度，窗口尺寸和位置不变。
- [ ] 在支持 `glass` 的平台，用高对比内容垫在小组件后方：淡化时原生模糊/材质消失，内容和底色淡到约 20%；把指针移入时内容立即恢复且原生材质重新出现。重复数轮，确认不叠加材质，也不会在恢复后丢失材质。
- [ ] 分别用降级后的 `glass`、`translucent` 和 `opaque` 验证淡化和唤醒；唤醒不应误加原生材质。小组件仍淡化时在设置页切换背景，确认新模式先保持淡化，原生材质只在所选模式实际支持玻璃且交互唤醒时出现。
- [ ] 分别用移动、按下鼠标、键盘操作和触摸操作重置计时；嵌套按钮、输入框、菜单与表单中的交互同样有效。
- [ ] 淡化后从顶部拖拽区开始拖动；确认按下时已恢复，不会以淡化状态卡住。
- [ ] 打开历史页和设置页并闲置超过 10 秒；确认这两个路由不淡化。往返主小组件多次，确认没有越来越快的重复计时或重复监听。

## 6. 可读性与状态覆盖

- [ ] 在浅色、深色和高对比背景内容上检查三种背景模式；完全显示时，任务名、计时、提示和按钮均可读。
- [ ] 分别停留在错误横幅、长暂停确认、暂停菜单、切换任务表单和确认状态直到淡化；确认悬停后立即恢复，首个正常点击可完成预期操作。
- [ ] 闲置淡化期间触发 M3 提醒脉冲；确认提醒动画不改变窗口高度，恢复显示后提醒档位和内容正确。

## 7. 拖拽与控件互不干扰

- [ ] 从顶部 8px 拖拽区拖动窗口，确认拖拽稳定且光标反馈正常。
- [ ] 点击或拖动按钮、输入框、选择框、暂停菜单和任务切换表单；确认这些控件不会误拖窗口。
- [ ] 在拖拽前后执行暂停、继续、完成、放弃、打开历史和打开设置；确认点击只触发一次。

## 8. M3 回归

- [ ] 按 `docs/m3-acceptance.md` 回归 near/due/overdue 视觉档位、脉冲队列、通知与静音。
- [ ] 在提醒状态下暂停任务并修改设置；确认暂停期间不产生新提醒，恢复后按新配置继续。
- [ ] 在隔离测试库中放入一项非法提醒设置以及自定义的有效阈值和开关。打开设置，确认只给无效字段显示默认值并出现紧凑警告；其他字段保留。验证保存时拒绝非法输入，保存合法设置后警告消失，重开设置仍显示保存结果。
- [ ] 检查提醒事件去重和轨迹导出，确认 M4 背景与淡化没有改变既有行为。
