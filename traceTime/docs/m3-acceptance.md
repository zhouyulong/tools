# M3 提醒功能验收清单

1. **分档视觉状态与颜色保持**：创建短时长任务，分别推进到预估时长的 75%、90% 和 100%，确认计时显示依次为琥珀、橙、红；进入下一档或超时前，当前档颜色持续保持。
2. **新事件动画与回落**：让任务首次进入 near 和 due 节点，确认每次收到新提醒事件时出现短时动画，并在约 3 秒后回落为对应档位的稳定颜色。
3. **默认系统通知策略**：使用默认设置运行任务，确认 due 节点产生系统通知；warn 和 near 节点不产生系统通知。
4. **超时重复通知与静音**：保持默认设置使任务超时，确认系统通知每 10 分钟重复一次；点击“静音”后不再通知，但红色超时视觉状态继续保留。
5. **设置即时影响与节点去重**：修改并保存提醒设置，确认后续轮询按新设置判定；对当前任务已经触发过的节点，不因设置修改或轮询而重复弹出。
6. **非法值禁止写入**：在设置窗口输入超出范围或非整数值并保存，确认页面显示错误，且本次编辑的所有设置均未写入。
7. **自动验证全绿**：运行 `pnpm test`、`pnpm check`、`pnpm build` 和 `cd src-tauri && cargo test`，确认全部通过且没有新增警告。
