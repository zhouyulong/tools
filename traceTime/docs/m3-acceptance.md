# M3 提醒功能验收清单

1. **实际计时与提醒档位分离**：预估 1 分钟，到期设置为 95% 时，第 57 秒提醒转红，但计时仍显示剩余 3 秒，不显示静音按钮。到期改为 150% 时，第 60 秒出现「静音超时」并开始显示「超时 +00:00:00」，直到第 90 秒提醒才转红。关闭提醒后，计时仍按预估时长从倒计时切换为超时正计时。自动测试另用 61 秒预估验证提醒阈值向下取整（95% 为第 57 秒）。
2. **临近档：橙色边框与字号**：进入 warn 档，计时文字变为琥珀色；进入 near 档，主计时文字变橙、字号略增大，边框变橙。near 动画结束后，保持橙框和略大的主计时，直到进入下一档。小组件不因字号变化而重新调整高度。
3. **到期档：短暂放大**：进入 due 档，主计时和边框变红，组件内容短暂放大到约 1.15 倍，在约 3 秒内回落；红框保持。若一次轮询同时触发多个节点，逐一播放各约 3 秒的动画，后到事件不覆盖前一动画。动画不改变窗口的自适应高度，也不重置正在操作的表单。
4. **超时提醒档：持续红框**：超过配置的提醒到期边界，红字与红框在动画结束后继续保留；实际超时计时仍以预估时长为准。第一次重复提醒在到期边界后一个周期（默认 10 分钟）触发。缩短或延长周期，确认从保存时尚未过去的新周期节点开始，不补发旧节点；从旧版数据库升级也不重发升级前已过的周期节点。
5. **通知与静音**：默认仅 due 和周期性 overdue 发送系统通知。点击「静音超时」只关闭该任务之后的超时系统通知，不影响视觉或轨迹，也不拦截由「到期 → 系统通知」开关控制的到期通知。
6. **暂停与设置**：在 near 或 overdue 后暂停，确认当前档持续显示。保持暂停并修改、保存到期百分比，确认视觉按新设置更新，但暂停期间不产生新的提醒事件或通知。
7. **设置保存反馈**：保存进行中，设置控件不可编辑；保存完成后显示「已保存」，再次编辑立即清除反馈。输入越界或非整数值时提示错误，且本次修改均未写入。
8. **轨迹与去重**：导出任务轨迹，确认每次新触发只追加一条 `reminder_fired` 事件，`detail` 可解析出 `node` 和 `level`；重复轮询不追加同节点事件。
9. **自动验证**：运行 `pnpm test`、`pnpm check`、`pnpm build` 和 `cd src-tauri && cargo test`，确认全部通过且无警告。
