# M1 手动验收清单

> 状态：待人工验收（实现后由用户执行）。本任务不运行 `pnpm tauri dev` 或 UI 自动化。

- [ ] 1. 输入任务名，选择 25 分钟和标签“科研”，点击“开始”后显示大计时，秒针持续跳动。
- [ ] 2. 点击“暂停”后出现 4 个原因按钮；选择“临时离开”后显示“已暂停”，计时停止增长。
- [ ] 3. 点击“继续”后计时恢复，并从暂停前的数值继续，不计入暂停时长。
- [ ] 4. 对照系统时间观察，净耗时等于各工作时段之和，暂停期间不增长。
- [ ] 5. 点击“放弃”后第一次变为“确认放弃?”；第二次点击后回到创建表单。
- [ ] 6. 点击“完成”后回到创建表单。
- [ ] 7. 重启应用后，运行中任务的净耗时不丢失，并从数据库恢复。
- [ ] 8. 全程点击小组件按钮时，记录焦点是否离开当前使用的其他程序；配置级基线允许短暂切换，M4 再做原生适配。
