# traceTime

桌面悬浮计时小组件：记录完成任务的真实时间与轨迹。

## 环境要求

- Node.js ≥ 20 与 pnpm
- Rust 工具链（rustup，stable）
- 系统依赖见 [Tauri 官方前置条件](https://tauri.app/start/prerequisites/)

## 开发模式（日常调试）

    pnpm install
    pnpm tauri dev

## 构建生产版本

    pnpm tauri build

构建产物（.app / .msi / .deb 等）位于 `src-tauri/target/release/bundle/` 下。仅验证可执行文件（不打安装包）可用：

    pnpm tauri build --no-bundle
    # 产物：src-tauri/target/release/traceTime（或平台对应名称）

## 日常使用

1. 启动后小组件显示创建表单：输入任务名，选择预计时长（预设或自定义分钟数）和标签（科研 / 行政 / 杂务 / 无标签），点"开始"。
2. 计时开始后小组件显示大号计时和剩余时间；点 ⏸ 暂停时需选一个原因（临时离开 / 被干扰 / 切换任务 / 其他）。
3. 暂停后点 ▶ 继续；点 ✔ 完成；点 ✕ 放弃（需二次确认）。
4. 暂停多个任务后会显示暂停任务标签；可继续最近暂停的任务，或创建新任务。
5. 点“历史”打开历史窗口，按日期查看已完成/已放弃任务及其时间轴。
6. 数据自动保存在本地 SQLite（系统应用数据目录），重启后运行中的任务会恢复。
7. 更多说明：设计文档见 `docs/2026-11-26-tracetime-design.md`；人工验收清单见 `docs/m1-acceptance.md` 与 `docs/m2-acceptance.md`。

## M2 新增

- 打断切换：切换任务时自动开始关联的新任务，并记录父任务
- 多暂停任务共存：暂停任务以标签列出，可继续最近暂停的任务
- 长暂停质询：暂停超过阈值时提供继续、完成或放弃操作
- 历史窗口与任务时间轴：按日期浏览任务，查看净时长、墙钟、预计与工作/暂停段

## 当前功能（M1）

- 创建任务（名称 + 预计时长 + 标签）并立即开始计时
- 暂停（记录原因：临时离开 / 被干扰 / 切换任务 / 其他）与继续
- 完成 / 放弃，历史任务列表查询（命令行 IPC 或后续 UI）
- 数据本地存储于系统应用数据目录
- 置顶悬浮窗：不进任务栏，配置级不抢焦点

## 技术栈

Tauri 2 + Svelte 5 + SQLite (rusqlite)。
